# Coalescing-pool comparison: RTX 6000 Ada

This result compares `PoolMemoryResource` with RMM
`pool_memory_resource` at commit
`c65202f52766e12c73e293b16d6a520a069d4afc`. Both binaries used the same
trace implementation, arguments, GPU/driver, and CPU affinity. Five paired
runs were alternated Rust then RMM.

## Environment

- GPU: NVIDIA RTX 6000 Ada Generation
- driver: 580.173.02
- CUDA toolkit: 12.9
- CPU: AMD Ryzen Threadripper PRO 5945WX 12-Cores
- kernel: Linux 6.8.0-136-generic
- Rust: 1.96.0-nightly (55e86c996 2026-04-02)
- C++: GCC 13.1.0
- affinity: CPU 17 via `taskset -c 17`

## Trace

```text
--resource=pool --allocations=10000 --max-allocation=1048576
--max-live-bytes=268435456 --warmups=2 --repetitions=7 --seed=24301
```

Each process reports the median complete-trace time over seven repetitions and
samples operation latency on the last repetition.

| pair | Rust ops/s | RMM ops/s | Rust p99 ns | RMM p99 ns |
| ---: | ---: | ---: | ---: | ---: |
| 1 | 2,720,142 | 1,840,850 | 641 | 1,072 |
| 2 | 2,704,916 | 1,832,960 | 641 | 1,063 |
| 3 | 2,696,664 | 1,843,090 | 641 | 1,072 |
| 4 | 2,729,616 | 1,850,080 | 802 | 1,062 |
| 5 | 2,742,762 | 1,875,650 | 631 | 1,052 |
| median | 2,720,142 | 1,843,090 | 641 | 1,063 |

For this trace, Rust throughput is 147.6% of RMM and Rust p99 latency is
60.3% of RMM. This passes the random-allocation release gates (at least 95%
throughput and no more than 110% p99) on this machine. It does not establish
parity for other hardware or the multi-stream, replay, container, and
synchronization benchmark families.

A deterministic 100,000-resample bootstrap over the five paired ratios gives
a 95% interval of 146.2%-147.8% for throughput and 59.8%-75.5% for p99. Raw
process output is preserved in
[`2026-08-23-rtx6000-ada-rust.jsonl`](2026-08-23-rtx6000-ada-rust.jsonl) and
[`2026-08-23-rtx6000-ada-rmm.jsonl`](2026-08-23-rtx6000-ada-rmm.jsonl).
