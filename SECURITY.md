# Security Policy

## Supported versions

This project is an experimental, pre-1.0 CUDA/Rust implementation. Only the
latest published or repository revision is supported for security reports.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private security advisory workflow for `StarGazerM/rccl`. Include the affected
commit, crate, CUDA/toolchain identity, reproduction steps, and impact. Do not
include credentials, private paths, or customer data.

If the advisory workflow is unavailable, contact the repository owner through
the verified GitHub profile and request a private reporting channel. Reports
will be acknowledged when practicable; fixes and disclosure timing are
coordinated with the reporter.
